## Evidencia

Los SVG de `evidencias/` se generan a partir de los informes de sprint y validaciones locales descritos en cada documento. No son capturas de Jira. Los huecos EVM, Jira, aceptación externa y video se declaran en los informes para evitar simular resultados.

## Estado de cierre

El repositorio permite reproducir un cierre técnico local. No acredita cierre académico, aceptación de interesados ni operación productiva. El [README principal](../../README.md) enlaza individualmente a los siete informes.
