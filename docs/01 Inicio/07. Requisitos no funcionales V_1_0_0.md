# Requisitos No Funcionales (RNF)

**Proyecto:** EcoLogística Huancayo — Optimizador de Rutas Sostenibles para "DistriRápido S.A.C."
**Versión:** 1.0.0 | **Fecha:** 28 de agosto de 2026

---

Los atributos de calidad se especifican mediante **Escenarios de Calidad** (ISO/IEC 25010 y arc42), con umbrales cuantitativos explícitos. Queda prohibido el uso de adjetivos calificativos sin métrica asociada.

| ID | Categoría ISO 25010 | Escenario de Calidad (Fuente → Estímulo → Entorno → Artefacto → Respuesta → Medida SLA) |
|---|---|---|
| RNF-001 | Eficiencia de Desempeño | **Fuente:** Operador. **Estímulo:** Ejecución de "Generar rutas" con 150 pedidos y 15 vehículos. **Entorno:** Operación normal, carga máxima. **Artefacto:** Motor de optimización (metaheurística). **Respuesta:** Retornar una solución de ruteo válida. **Medida:** Tiempo de respuesta ≤ 45 segundos; re-optimización ante cambios ≤ 30 segundos. |
| RNF-002 | Seguridad | **Fuente:** Atacante externo. **Estímulo:** Intento de inyección SQL en el endpoint de autenticación. **Entorno:** Producción. **Artefacto:** API Gateway / capa de autenticación. **Respuesta:** Bloquear la petición, registrar el evento de auditoría. **Medida:** 0% de vulnerabilidades críticas OWASP Top 10 explotables en pruebas de penetración. |
| RNF-003 | Fiabilidad (Disponibilidad) | **Fuente:** Infraestructura cloud. **Estímulo:** Caída de un nodo del servidor de aplicación en horario operativo (5:00-22:00). **Entorno:** Operación continua. **Artefacto:** Servicio backend / base de datos. **Respuesta:** Failover automático o reinicio del servicio. **Medida:** Disponibilidad ≥ 99.5% en horario operativo; RTO ≤ 60 segundos. |
| RNF-004 | Adecuación Funcional (Precisión Funcional) | **Fuente:** Motor de cálculo de indicadores. **Estímulo:** Cálculo de emisiones de CO₂ y ahorro de combustible por ruta. **Entorno:** Cierre diario de rutas. **Artefacto:** Módulo de indicadores de sostenibilidad. **Respuesta:** Calcular el indicador según el factor de emisión declarado del vehículo. **Medida:** Margen de error ≤ 2% respecto al cálculo de referencia validado manualmente. |
| RNF-005 | Usabilidad | **Fuente:** Conductor con educación básica y bajo dominio tecnológico. **Estímulo:** Consulta de su ruta asignada del día en el "modo conductor". **Entorno:** Uso en campo, posible conexión 3G. **Artefacto:** Interfaz simplificada móvil. **Respuesta:** Mostrar ruta, entregas pendientes y alertas con iconografía de alto contraste. **Medida:** Tiempo de aprendizaje ≤ 10 minutos con guía; tasa de error de navegación ≤ 5% en pruebas de usabilidad con 10 conductores. |
| RNF-006 | Compatibilidad / Portabilidad | **Fuente:** Usuario con conexión limitada. **Estímulo:** Acceso al sistema desde zonas periféricas de Huancayo (Chilca alta, Cochas) con cobertura 3G. **Entorno:** Condiciones reales de campo. **Artefacto:** Aplicación web responsive. **Respuesta:** Cargar la vista esencial (ruta del día) de forma funcional. **Medida:** Tiempo de carga de la vista esencial ≤ 5 segundos en conexión 3G simulada (384 kbps). |
| RNF-007 | Mantenibilidad | **Fuente:** Equipo de desarrollo. **Estímulo:** Incorporación de una nueva metaheurística de optimización (ej. Colonia de Hormigas) al motor existente. **Entorno:** Ciclo de mantenimiento evolutivo. **Artefacto:** Módulo de optimización (arquitectura hexagonal/modular). **Respuesta:** Integrar el nuevo algoritmo sin modificar los módulos de gestión de flota, pedidos o conductores. **Medida:** Cobertura de pruebas unitarias del núcleo de optimización ≥ 70%; 0 regresiones en la suite de pruebas existente. |
| RNF-008 | Escalabilidad (Capacidad) | **Fuente:** Crecimiento operativo de "DistriRápido S.A.C." **Estímulo:** Incremento del volumen de pedidos hasta 1,000 diarios y 50 vehículos. **Entorno:** Expansión proyectada a distritos adicionales del Valle del Mantaro. **Artefacto:** Arquitectura backend (contenedores). **Respuesta:** Escalar horizontalmente los servicios de cómputo del motor de optimización. **Medida:** Degradación de tiempo de respuesta ≤ 20% al pasar de 150 a 1,000 pedidos, manteniendo el SLA de RNF-001 mediante escalamiento automático. |
| RNF-009 | Accesibilidad | **Fuente:** Usuario administrativo o auditor con limitaciones visuales o motrices. **Estímulo:** Navegación por el dashboard de indicadores. **Entorno:** Uso en oficina. **Artefacto:** Interfaz web administrativa. **Respuesta:** Permitir navegación completa por teclado y lectura por software asistivo. **Medida:** Cumplimiento de WCAG 2.1 nivel AA verificado con herramienta automatizada (0 errores críticos) y prueba manual con lector de pantalla. |
| RNF-010 | Eficiencia Energética (Green Software) | **Fuente:** Operación continua del sistema en la nube. **Estímulo:** Ejecución diaria del motor de optimización y consultas del dashboard. **Entorno:** Producción 24/7. **Artefacto:** Backend y base de datos. **Respuesta:** Minimizar ciclos de CPU mediante consultas SQL optimizadas e índices adecuados. **Medida:** Reducción ≥ 15% en tiempo de CPU de las consultas críticas respecto a una implementación sin índices, verificado con `EXPLAIN ANALYZE`. |

---

## Notas de Cumplimiento Normativo Asociado

- **RNF-002** se alinea con la Ley N° 29733 (Ley de Protección de Datos Personales del Perú) para el manejo de datos de clientes y conductores.
- **RNF-005** y **RNF-009** responden a la necesidad de accesibilidad identificada en el marco de elicitación holística (Documento 06), dado el perfil educativo diverso de los conductores.
- **RNF-008** se sustenta en el objetivo estratégico de escalabilidad declarado en la Declaración de Visión del Producto (Documento 03).
